# Agent design guide, approved scope

사용자는 2026-10-31에 AI용 진입, 주제별 개념, Agent/MCP/하네스 설계, 계약/예제/검증, 원문 쪽별 반영표 구조를 승인했다.

두 사용자 제공 PDF 53쪽과 125쪽을 원본 변경 없이 읽는다. 같은 강의의 보관 HTML은 판독 보조 자료로 쓰고 대응 상태를 밝힌다. 37개 및 59개 주제는 안정적인 ID로 연결한다. 원문 파일, OCR 전문, 사용자 개인 경로와 비공개 노트는 공개 패키지에 넣지 않는다.

문서는 한국어로 충분히 설명하고 AI가 필요한 주제만 검색할 수 있는 JSON 색인과 작업별 읽기 경로를 제공한다. 원문 재서술, AI 설계 보완, 공식 문서의 버전 차이, 오프라인 실행 확인을 구별한다. 실서비스 연결이나 모든 쪽의 수동 검토를 수행하지 않았다면 완료했다고 표시하지 않는다. 공개 GitHub 업로드 전 완성본을 사용자가 검토할 수 있게 한다.

합격 조건: 96개 주제의 고유 ID와 본문 목적지, 178쪽의 판독/대응 상태, 설계 템플릿, MCP/하네스/안전/평가 지침, 실행 가능한 오프라인 예제, 링크/색인/예제 검사, 내려받을 ZIP. Git push와 원문 재배포는 이 작업에 포함하지 않는다.

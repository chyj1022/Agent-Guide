# AGT-052 C-04, 웹 조사 에이전트

출처: **SRC-02**, 보조 HTML 구간 [#s-8bedad91](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-8bedad91). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

C-04는 웹 검색 후보에서 본문을 읽고 실제 근거를 인용해 조사 결과를 작성하는 실습이다. 검색과 읽음 및 인용 검증 상태를 구분해야 한다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 조사할 주제 |
| 처리 | web_search로 후보를 모으고 fetch_page로 2~3개 본문을 추출한다. 최종 답의 URL을 수집 이력과 대조하고 부족한 근거는 미확인으로 남긴다. |
| 출력 | 출처가 있는 보고서 또는 확인 실패 |

## 자료의 예제와 학습 포인트

자료는 검색 사이트 HTML을 정규식으로 읽는 교육 구현과 trafilatura 본문 추출을 사용한다. 실무는 검색 API로 바꾸고 재작성 횟수를 제한하라고 안내한다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

검색과 출처 연결 학습에 적합하다. 검색 결과에 존재한다는 사실만으로 읽고 검증한 자료로 취급하면 안 된다.

## 실패 조건과 해석 경계

원문의 SEEN은 검색 후보를 저장하므로 verify는 실제 본문 읽음까지 증명하지 못한다. 리다이렉트와 DNS 및 사설 IP 검사가 부족하고 DuckDB HTML이라는 표기는 검색 사이트 맥락의 오기다.

## AI 작성 복습 문답

**질문:** 출처 URL이 검색 결과에 있으면 주장의 근거 검증이 끝나는가?

**설명 답안:** 아니다. 본문을 실제로 읽었는지와 그 내용이 주장을 뒷받침하는지까지 확인해야 한다.

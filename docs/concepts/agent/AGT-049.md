# AGT-049 C-01, 프레임워크 없이 만드는 첫 에이전트

출처: **SRC-02**, 보조 HTML 구간 [#s-4c0783cb](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-4c0783cb). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

C-01은 프레임워크 없이 두 도구를 연결해 모델 요청과 실제 실행 및 관찰의 왕복을 확인하는 실습이다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 서울과 제주 기온 차이 또는 부산 기온의 세 배 질문 |
| 처리 | 고정 날씨 사전에서 기온을 조회하고 calculate로 연산한다. assistant 요청과 tool 결과를 순서대로 메시지에 넣고 최대 8단계로 제한한다. |
| 출력 | 도구 궤적과 계산 결과 또는 상한 중단 |

## 자료의 예제와 학습 포인트

자료의 서울=3, 부산=8, 제주=11은 가짜 데이터다. 예시 기대값은 서울과 제주 차이 8도, 부산의 세 배 24이며 인사는 도구 없이 끝나는 비교 사례다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

루프와 도구 선택 이해에 적합하다. 실제 기상 관측 서비스나 안전한 범용 계산기를 구현했다고 해석하면 안 된다.

## 실패 조건과 해석 경계

문자 허용 목록과 eval은 완전한 계산 자원 통제가 아니다. 거대한 지수나 긴 식은 자원을 소모할 수 있고 형식 오류와 예산 제어가 별도로 필요하다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

사칙연산 AST 해석기와 연산 수 및 숫자 크기 제한을 사용한다. 모르는 도시, 항상 실패하는 도구, 2단계 한도를 각각 오프라인으로 검증한다.

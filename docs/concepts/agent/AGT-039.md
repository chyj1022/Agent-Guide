## 정의와 필요한 이유

단계별 자가 실습은 도구 선택, 실패와 제동을 직접 관찰하고 개선을 측정하도록 구성된 학습 과제다. 과제 제시와 수행 완료는 구분한다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 작은 직접 루프와 평가할 질문 목록 |
| 처리 | 도구 추가, description 제거와 복원, 제한된 실패 주입, 궤적 기록과 예산을 차례로 실험한다. 수정 전후를 같은 질문으로 비교한다. |
| 출력 | 선택 혼동표, 성공률과 비용 및 상한 발동 기록 |

## 자료의 예제와 학습 포인트

자료는 질문 10개를 3회 실행하는 평가, 헷갈리는 두 도구의 언제 안 쓰나 추가, 회차와 토큰 및 시간과 동일 호출의 네 상한을 각각 재현하는 과제를 제시한다.

## 적용할 조건과 피할 상황

학습 내용의 작동 원리를 검증하는 연습에 적합하다. 과제가 있다는 이유로 사용자가 모두 구현하거나 숙달했다고 기록하지 않는다.

## 실패 조건과 해석 경계

상한 없는 무한 루프를 실제 유료 호출로 오래 실행할 필요는 없다. 실패 실험에도 제한된 예산과 가짜 도구를 사용해야 한다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

오프라인 가짜 모델로 각 가드 발동을 먼저 확인하고 유료 비교는 명시적인 작은 테스트 예산 안에서 실행한다.

## AI 작성 복습 문답

**질문:** 도구 설명 개선 효과를 어떻게 비교하나?

**설명 답안:** 같은 질문과 반복 수를 사용해 수정 전후 선택 정확도와 혼동한 도구 및 비용을 함께 비교한다.

# AGT-006 처음 만드는 사람이 겪는 다섯 가지 오해

출처: **SRC-02**, 보조 HTML 구간 [#s-9e2cf43b](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-9e2cf43b). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

초기 오해를 풀려면 판단과 실행을 분리해야 한다. 모델 성능이나 프롬프트만으로 권한과 반복 문제를 해결할 수 없다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 모델이 만든 도구 호출 요청 |
| 처리 | 허용 목록을 확인하고 서버가 인자를 검증한다. 실행 결과를 메시지로 넣고 호스트 루프가 다음 호출이나 종료를 결정한다. |
| 출력 | 허용된 도구 결과 또는 거부와 오류 상태 |

## 자료의 예제와 학습 포인트

자료는 모델이 도구와 루프를 실행한다는 오해, 프롬프트가 안전을 보장한다는 오해, 큰 모델과 많은 기억이면 해결된다는 오해를 다룬다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

장애 원인을 모델 탓으로만 돌릴 때 책임을 나누는 데 적합하다. 프롬프트를 보안 경계로 사용하기에는 부적합하다.

## 실패 조건과 해석 경계

대화 전체 저장은 오래된 실패와 모순을 함께 전달한다. 좋은 모델도 모호한 도구 설명과 없는 종료 조건을 보완하지 못한다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

권한과 중단 여부는 모델 출력과 독립된 코드로 검사한다. 기억은 출처와 유효 시점에 따라 선택한다.

## AI 작성 복습 문답

**질문:** 모델을 바꾸기 전에 무엇을 확인해야 하나?

**설명 답안:** 도구 설명, 인자 검증, 반환 형식, 종료 조건과 권한을 확인한다.

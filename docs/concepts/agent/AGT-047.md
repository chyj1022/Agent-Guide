# AGT-047 회귀를 막는 CI

출처: **SRC-02**, 보조 HTML 구간 [#s-6f136f35](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-6f136f35). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

CI 회귀 게이트는 품질, 금지 행동과 비용 기준을 기계적으로 검사해 조용한 성능 저하를 드러낸다. 빠른 오프라인 검사와 유료 평가를 분리한다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 코드 변경과 평가 결과 JSON |
| 처리 | 단위 및 재생 검사는 매 변경에서 실행한다. 실시간 평가는 정해진 환경에서 실행하고 여러 지표의 미달 항목을 모아 실패 코드로 반환한다. |
| 출력 | 통과 또는 수치가 있는 기준 미달 보고서 |

## 자료의 예제와 학습 포인트

자료는 accuracy 0.80, tool_choice 0.90, refusal 0.95, 중앙 단계 6과 사례당 0.03달러라는 예시 게이트를 제시한다. 이 수치는 업무별로 정할 기준이지 보편 표준이 아니다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

반복 변경과 배포 검토가 있는 프로젝트에 적합하다. 실시간 키를 신뢰하지 않는 외부 PR에 제공하는 흐름은 피해야 한다.

## 실패 조건과 해석 경계

적은 샘플의 한 번 평가는 변동성이 크다. 프롬프트 변경만이 아니라 문서와 모델 변화도 결과에 영향을 준다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

위험 행동은 개별 실패를 차단하고 통계 지표는 반복 수와 기준선 차이를 남긴다. 평가 예산과 비밀 접근을 제한하고 실제 실행 버전을 artifact에 저장한다.

## AI 작성 복습 문답

**질문:** 정답률만 게이트에 두면 어떤 회귀를 놓치나?

**설명 답안:** 거부 실패, 단계 증가와 비용 및 지연 상승을 놓칠 수 있다.

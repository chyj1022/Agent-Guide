# AGT-046 궤적을 테스트한다, 재현 가능하게 만들기

출처: **SRC-02**, 보조 HTML 구간 [#s-4fb62faf](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-4fb62faf). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

궤적 녹화와 재생은 고정된 모델 응답을 사용해 루프와 금지 행동 및 순서를 반복 검사하는 방식이다. 실시간 모델 품질 평가는 별도로 필요하다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 모델 요청과 저장된 응답 녹화본 |
| 처리 | 요청을 정규화해 키를 계산하고 재생 모드에서는 일치하는 응답만 사용한다. 없으면 네트워크로 넘어가지 않고 명시적으로 실패한다. |
| 출력 | 재현 가능한 실행과 궤적 제약 검사 결과 |

## 자료의 예제와 학습 포인트

자료는 환불 규정 확인, 주문 조회 뒤 승인 요청, 승인 없는 issue_refund 금지와 5단계 상한을 시험한다. 녹화본을 변경 검토 가능한 형태로 저장하는 예를 제시한다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

오프라인 CI의 제어 흐름 회귀 검사에 적합하다. 과거 녹화가 현재 모델의 선택 능력까지 검증하는 것은 아니다.

## 실패 조건과 해석 경계

자료 키가 도구 이름만 넣으면 description과 스키마 변경을 놓친다. 모델 옵션이나 도구 결과 변화도 동일 키에 숨을 수 있다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

전체 도구 정의, 모델과 생성 옵션, 정책 및 fixture 버전을 키에 포함한다. 개인정보를 정제한 녹화만 보관하고 실시간 평가는 분리한다.

## AI 작성 복습 문답

**질문:** 녹화본이 없을 때 실제 모델을 자동 호출해도 되나?

**설명 답안:** 재생 테스트의 비용과 재현성을 깨므로 실패를 명시하고 별도 승인된 기록 절차로 갱신하는 편이 낫다.

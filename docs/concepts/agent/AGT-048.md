# AGT-048 이 실습을 하는 법

출처: **SRC-02**, 보조 HTML 구간 [#s-e2a2f88f](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-e2a2f88f). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

클론 코딩 안내는 열 개 실습을 기초 루프에서 도구 안전, 그래프와 배포까지 연결하는 학습 경로다. 설치 지시와 예상 결과는 실행 사실이 아니다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 학습 목표와 준비된 실습 환경 |
| 처리 | C-01 루프, C-02 파일, C-03 SQL, C-04 웹, C-05 RAG, C-06 리뷰, C-07 승인, C-08 MCP, C-09 협업, C-10 평가와 API 순으로 진행한다. |
| 출력 | 실습별 관찰 기록과 미완료 항목 |

## 자료의 예제와 학습 포인트

자료는 가상환경, openai와 httpx 및 dotenv, pydantic을 공통 준비로 제시하고 이후 그래프, MCP, 본문 추출과 SQL 패키지를 추가한다. 막히면 도구 단독 호출, 메시지 확인, 도구 축소와 상한 축소 순으로 보도록 한다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

순차 학습과 개념 연결에 적합하다. 원문이 복사 실행을 안내해도 현재 버전 호환성과 완성도를 확인해야 한다.

## 실패 조건과 해석 경계

원문 코드에는 생략된 함수, 추가 패키지와 버전 차이가 있다. API 키와 파일 쓰기 및 외부 호출이 있어 문서 판독 중 실행하면 안 된다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

실습마다 오프라인 관찰, 실모델 호출, 파일 변경과 실제 운영을 구분한 기록지를 사용한다. 비밀과 fixture를 분리하고 패키지 버전을 고정한다.

## AI 작성 복습 문답

**질문:** 실습 안내를 읽었다고 구현 완료로 기록할 수 있나?

**설명 답안:** 아니다. 자료 보유, 개념 학습, 직접 실행과 수정 및 운영 적용은 서로 다른 상태다.

# AGT-017 컨텍스트가 넘칠 때 압축한다

출처: **SRC-02**, 보조 HTML 구간 [#s-423c4d1e](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-423c4d1e). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

컨텍스트 압축은 정보 종류에 따라 보존, 요약, 외부 보관과 제거를 다르게 적용하는 과정이다. 중요한 결정과 실패를 유지해야 탐색이 되풀이되지 않는다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 길어진 대화, 큰 조회 결과와 로그 |
| 처리 | 원래 요청과 정책 및 최근 흐름을 남긴다. 중간 기록은 사실, 결정 이유, 실패와 남은 일로 압축한다. 큰 본문은 파일로 빼고 참조와 미리보기를 넣는다. |
| 출력 | 압축 사실이 표시된 짧은 컨텍스트와 재조회 가능한 자료 참조 |

## 자료의 예제와 학습 포인트

자료는 앞 2개와 뒤 6개 메시지를 유지하고 40,000토큰을 기준으로 중간을 요약한다. 4,000자 이상 결과는 외부 저장하고 앞 600자를 보여 주는 예도 있다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

장기 조사와 큰 문서 처리에 적합하다. 모든 메시지를 동일한 요약으로 바꾸면 제약과 실패를 잃을 수 있다.

## 실패 조건과 해석 경계

메시지를 임의로 자르면 도구 호출과 결과의 짝이 깨진다. 요약은 사실을 누락하거나 잘못 바꿀 수 있고 파일 참조는 재접근 권한이 있어야 유용하다.

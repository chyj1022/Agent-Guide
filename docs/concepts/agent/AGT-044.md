# AGT-044 에이전트를 어떻게 재나

출처: **SRC-02**, 보조 HTML 구간 [#s-1e0cdbbf](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-1e0cdbbf). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

에이전트 평가는 최종 정답, 도구 선택, 경로 효율과 올바른 거부를 분리해 측정하는 것이다. 한 점수는 서로 다른 실패를 숨길 수 있다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 답할 수 있는 질문, 모르는 질문과 도구 금지 사례 |
| 처리 | 필수 또는 대체 가능한 도구, 금지 도구, 핵심 내용과 단계 예산을 검사한다. 거부 사례만 따로 성공률을 집계한다. |
| 출력 | 축별 점수와 실패 사례 및 단계 분포 |

## 자료의 예제와 학습 포인트

자료는 환불 요청, 규정에 없는 중고 환불과 인사말을 대비한다. 시작용 20건 중 약 3분의 1을 답할 수 없는 질문으로 구성하는 제안을 준다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

프롬프트와 도구 변경 비교 및 회귀 방지에 적합하다. 정답률 하나나 정확한 문장 일치만으로 품질을 판정하지 않는다.

## 실패 조건과 해석 경계

키워드 포함은 의미 정확성을 보장하지 않는다. 최대 단계 필드가 있어도 실행기나 게이트가 실제 검사하지 않으면 요구가 적용되지 않는다.

# AGT-050 C-02, 파일 정리 에이전트

출처: **SRC-02**, 보조 HTML 구간 [#s-d7292328](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-d7292328). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

C-02는 파일 목록을 보고 정리 계획을 만든 뒤 승인된 이동만 실행하는 실습이다. 경로 범위와 변경 전 확인을 함께 배운다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 연습 workspace를 종류별로 정리하라는 요청 |
| 처리 | 목록 확인, 분류 계획, 하위 폴더 생성과 한 파일씩 이동 순으로 진행한다. src와 dst를 작업 폴더 안으로 제한하고 이동 직전에 y/n을 받는다. |
| 출력 | 승인된 이동 기록과 남긴 파일 목록 |

## 자료의 예제와 학습 포인트

자료 seed는 report.pdf와 photo1.jpg 등 이름을 가진 더미 텍스트 파일을 만든다. 진짜 PDF나 이미지 내용 분석이 아니며 거부한 파일을 반복 시도하지 않는 것이 기대 동작이다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

안전한 파일 도구의 학습과 변경 계획 검토에 적합하다. 기존 실사용 폴더에 원문 seed를 실행하는 방식은 부적합하다.

## 실패 조건과 해석 경계

seed는 같은 이름 파일을 덮어쓸 수 있다. 이동의 가역성은 목적지 충돌과 덮어쓰기 및 원본 보관 여부에 달렸으며 승인 전 폴더 생성도 상태 변경이다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

새 임시 fixture만 사용하고 충돌 시 거부 또는 새 이름 정책을 둔다. 전체 이동 계획과 원본 해시 및 undo 기록을 승인 대상에 포함한다.

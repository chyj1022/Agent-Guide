# AGT-058 C-10, 평가 세트와 API 배포

출처: **SRC-02**, 보조 HTML 구간 [#s-208429de](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-208429de). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

C-10은 상담 루프를 평가 계약과 API로 감싸 서비스 형태를 연습하는 단계다. 평가 실행과 서버 포장이 운영 완성을 자동 보장하지는 않는다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 고정 평가 사례와 HTTP 질문 요청 |
| 처리 | 네 축을 평가하고 게이트를 적용한다. 요청 ID와 사용자 한도를 기록하며 /ask는 JSON, /ask/stream은 SSE로 진행을 전한다. |
| 출력 | 평가 보고서, 통과 여부와 API 응답 또는 제한 상태 |

## 자료의 예제와 학습 포인트

자료는 환불 기간, 제주 배송, 중고와 해외 미확인 및 인사의 5사례, accuracy 0.80, tool_choice 0.90과 refusal 1.00, 중앙 단계 4를 예로 든다. 50,000토큰 일일 한도는 프로세스 내 사전이다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

평가와 서비스 경계를 연결하는 학습에 적합하다. 제공된 app.agent와 stream_agent의 완성 구현 및 실제 배포는 별도 확인이 필요하다.

## 실패 조건과 해석 경계

임의 x-user-id 헤더는 인증이 아니다. 재시작과 다중 인스턴스에서 한도 우회가 가능하다. 사례별 steps_ok를 출력해도 게이트는 중앙값만 보아 개별 상한 실패를 놓칠 수 있다.

## AI 설계 보완

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

검증된 인증 주체를 사용하고 한도는 외부 저장소에서 원자적으로 관리한다. 사례별 안전과 단계 실패를 게이트에 포함하고 스트림 단절에도 사용량을 정산한다.

## AI 작성 복습 문답

**질문:** 헤더에 사용자 ID가 있다고 인증이 끝나는가?

**설명 답안:** 아니다. 신뢰할 수 있는 인증 계층이 확인한 주체와 요청 권한을 사용해야 한다.

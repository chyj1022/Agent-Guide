# AGT-013 프레임워크 없이 40줄로 만드는 첫 에이전트

출처: **SRC-02**, 보조 HTML 구간 [#s-b73d1ba8](https://tech-learning-hub.pages.dev/courses/ai-agent/complete-guide.html#s-b73d1ba8). 사용자 제공 PDF와의 쪽별 대응 및 판독 상태는 [출처 대응표](../../../sources/SRC-02.md)에서 구분한다. 온라인 주소는 보관 HTML의 사이트 원문 링크이며 현재 온라인 내용과의 일치는 확인하지 않았다. 이 문서는 강의 자료를 바탕으로 AI가 재서술한 개념 설명이며 개인의 구현이나 운영 성과 기록이 아니다.

## 정의와 필요한 이유

작은 직접 구현 루프는 프레임워크가 감추는 왕복을 이해하는 학습 기준선이다. 도구 등록, 명세, 모델 호출, 관찰 추가와 종료가 핵심이다.

## 입력에서 출력까지

| 단계 | 구체적 내용 |
|---|---|
| 입력 | 서울 날씨와 12+30 계산을 함께 요청한 질문 |
| 처리 | 최대 6턴 안에서 모델을 호출한다. 도구 요청이 있으면 registry 함수를 실행하고 관찰을 추가한다. 요청이 없으면 답을 반환한다. |
| 출력 | 도구 관찰을 반영한 답 또는 턴 상한 메시지 |

## 자료의 예제와 학습 포인트

자료의 get_weather는 서울과 부산의 가짜 날씨 사전을 사용하고 add는 합을 계산한다. 제시 출력의 23도와 42는 강의 예시이며 이번 실행 결과가 아니다.

자료의 코드와 모델명은 당시 흐름을 이해하기 위한 예시다. 이 문서는 외부 API나 원문 코드를 실행한 결과가 아니다. 구현 전 사용 중인 SDK, 전송 방식과 패키지 버전을 현재 공식 문서와 대조한다.

## 적용할 조건과 피할 상황

도구가 적고 중단 재개가 필요 없는 학습과 기준선 구현에 적합하다. 복잡한 승인과 장기 상태가 있으면 추가 실행 제어가 필요하다.

## 실패 조건과 해석 경계

예시 루프에는 운영 수준의 모든 인자 검증과 비용 및 취소 처리가 포함되어 있지 않다. 도구 요청이 없다는 사실도 업무 성공의 충분조건은 아니다.

아래는 원문의 수행 결과가 아닌 **AI 설계 제안과 원문 예시의 한계 분석**이다.

## 왜 필요하고 무엇인가

자동화와 에이전틱 시스템을 가르는 기준은 실행 경로를 누가 결정하는가이다. 워크플로는 사람이 정한 분기를 따르고, 에이전트는 목표와 관찰을 받아 실행 중 다음 행동을 고른다. 따라서 사전에 경로를 검토하는 것만으로 품질과 안전을 판단하기 어렵다.

## 입력에서 출력까지

트리거와 데이터를 받아 검증, 변환, 저장을 수행하면 고정 경로의 자동화이다. 목표를 받아 도구를 선택하고 결과를 관찰해 재판단하면 에이전틱 흐름이다. 출력은 최종 결과와 함께 실행 이력과 검증 결과를 포함한다.

## 원자료의 구체적인 설명

자료의 직선 도식은 입력에서 검증, 변환, 저장으로 이어진다. 다른 도식은 판단 루프가 도구 A, B, C를 고르는 구조다. 사전에 모든 행동 목록을 약속하기 어려우므로 도구 권한과 실제 결과, 남은 기록이 중요한 검토 대상이 된다.

## 적합한 조건과 피할 조건

예외와 도구 선택을 미리 열거하기 어려운 조사에 적합하다. 경로가 확정된 단순 변환에 자율 루프를 추가하면 비용과 불확실성이 더 커질 수 있다.

## 한계와 확인할 점

결과 검사만으로 실행 중 피해를 막지는 못한다. 워크플로도 보안과 데이터 검증이 필요하므로 경로 검토만으로 안전하다는 설명은 단순화다.

## 설계 적용, AI 보완

모델이 선택할 수 있는 결정, 접근 자원, 중단 조건을 명시한다. 실행 전에 도구 경계에서 정책을 검사하고 결과 검증과 결합한다.
